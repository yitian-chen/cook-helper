厨房助手 · 语音测试

先确认能录到声音、能听到回放，再测试云端识别和播报。无需阅读接口返回的数据。

工作方式：Python 从所选麦克风录音 → 所选云端识别 → Agent 处理 → 所选云端语音合成 → 本机音箱播放。支持分别选择阿里云或讯飞。录音和回放不联网，未调用操作系统听写；只有点击识别、合成或完整流程才请求云端。

1. 选择麦克风和音箱

这里使用的是运行 Python 服务那台设备的麦克风和音箱。请先调低音量。

连接/断开设备后先重新扫描，再重新选择并应用；扫描会停止放音并清除旧编号，录音或云端处理期间不可扫描。

2. 录一段话，再听回放（不联网）

点击开始后，说“我想做番茄炒鸡蛋”，然后点击结束。

尚未录音。录音时绿色音量条应随说话变化；最终以回放是否清楚为准。

4. 输入文字，让音箱说出来

此步骤调用云端语音合成。它只测试播报，无需连接 Agent。

首次收到音频就开始播放；相同文字再次播报可以复用本地缓存。计时不包含蓝牙音箱自身延迟。
